VAULT//R v0.3 — MULTI PHOTO / EXTENDED LOCAL VAULT

■ v0.3で変わったこと
・1作品につき最大8枚の写真を登録可能
・Androidのファイル選択で複数写真をまとめて選択可能
・登録画面のサムネイルをタップして表紙写真を変更
・不要な写真は登録画面から個別削除
・詳細画面は左右スワイプで写真を閲覧
・一覧には複数写真の枚数を表示
・v0.2までの1枚写真データを自動的に複数写真形式へ移行
・v0.2のローカルデータを同じGitHub Pages URL上で自動引き継ぎ
・保存先をIndexedDBへ拡張。100件以上＋複数写真を想定した構成へ更新
・写真は最大960px / JPEG圧縮して端末内へ保存
・バックアップ形式をv0.3へ更新（旧バックアップも読み込み可能）
・PWAのキャッシュをv0.3へ更新し、今後のアップデート反映を改善

■ 重要：既存データについて
同じGitHub Pages URL（例: https://ユーザー名.github.io/vault-r/）をそのまま更新してください。
v0.3を最初に起動すると、v0.2で登録した作品を自動で新しい保存形式へコピーします。
念のため、更新前にVAULT → EXPORT BACKUPを1回実行しておくのがおすすめです。

■ 複数写真の使い方
1. ADD または EDIT を開く
2. PHOTOS欄を押す
3. Androidのギャラリー / ファイル選択で複数枚選ぶ
4. サムネイルをタップすると、その写真が表紙になる
5. ×で不要な写真を削除
6. SAVE TO VAULT
7. 詳細画面では写真を左右スワイプ

■ 写真上限
1作品あたり最大8枚。
容量を抑えるため、保存時に自動で圧縮します。端末やChromeのデータ削除では消える可能性があるため、定期的にバックアップしてください。

■ GitHub Pagesでv0.2から更新する場合
リポジトリのルートで以下を同名のままアップロードしてコミットしてください。
・index.html
・manifest.webmanifest
・sw.js
・README.txt
assetsフォルダの3画像はv0.2と同じなので、そのままでOKです。

ホーム画面に入れてあるVAULT//Rは削除・再インストール不要です。
更新後に一度アプリを完全に閉じて開き直してください。古い画面が残る場合はChromeでGitHub Pages版を1回開いて再読み込みしてください。
